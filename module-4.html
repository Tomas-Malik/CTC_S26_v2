AI Literacy 101 · Module 4

Search & Verify

Ground an AI assistant in a real document, pull out exact facts, then find out why a summary is the part you actually have to check.

~100 minutes Level 1 Who it’s for: everyone

TL;DR

You’ll ask an AI assistant a specific question — first with no documents attached, then grounded in a real, current UIC policy document — and feel the difference for yourself. Then you’ll pull exact facts out of running text and a table to check a realistic claim, and finally verify a summary that has no single sentence you can check it against.

Prerequisites None — this module stands on its own, no prior modules required.
What you’ll need A laptop and AI assistant access — any tool that can accept a file upload or a long paste of text (Claude, ChatGPT, or similar). No coding and no code execution required.
Who it’s for Everyone — no technical background required.

After this module, you’ll be able to

  • 1 Ground an AI assistant in a specific real document, instead of letting it answer from whatever it happened to learn in training.
  • 2 Pull an exact fact out of a document and check it — whether it’s sitting in running text or a table.
  • 3 Verify a summary or a “what does this mean” answer, even when there’s no single verbatim sentence to check it against.

Preparation

  • 1 Read the facilitator manual in full, especially “The verified answer key” — the fastest way to recognize a correct catch when you see one.
  • 2 Do all three beats yourself with a real AI assistant before teaching it — the Quick Start in the facilitator manual walks through this end to end.
  • 3 Skim the deck’s speaker notes for timing and beat-by-beat framing language.
  • 4 Confirm your room’s AI assistants can accept a file upload or a long paste of text — that’s the only logistics dependency.
  • 5 Keep your own tested answers from the Quick Start on hand — ready to share only if a group gets genuinely stuck, not up front.

This module grounds learners in a real, current UIC policy document (the CS Department’s Graduate Program Requirements) rather than a fictional case file — it’s a literacy exercise, not official advising. The facilitator manual documents exactly which claims to check and how to verify a summary answer — deliberately not in the lab guide or the deck. Reading it counts as spoiling the diagnostic for yourself, in a good way; just don’t narrate it to learners before they’ve tried. An earlier, fully fictional version of this module is archived at materials/module-4/archive/elston-heights-fictional-scenario/ if you’d rather teach that scenario instead.
