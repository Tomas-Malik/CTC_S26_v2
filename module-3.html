AI Literacy 101 · Module 3

Data On Demand

From static report to living webpage: build a real, interactive tool with AI as your technical partner — then find out what keeping it “living” actually costs.

Level 2 Prerequisite: Module 2 ~110 minutes

TL;DR

You’ll build an actual webpage — served locally, reading a folder of Pinnacle Peak revenue data, with real filter/sort/toggle interactivity — using AI as your technical partner. Then new numbers arrive, you hit rebuild, and something goes wrong on purpose. The second half of the module is entirely about noticing that and fixing it for real.

Prerequisites Module 2, completed — this module reuses its data, its scenario, and the verification habits it built, now aimed at a pipeline instead of a paragraph.
What you’ll need A laptop, an AI assistant that can write and run code on your machine (not just chat — e.g. Claude or ChatGPT with code execution, or a coding-capable tool), and Python 3 available for the simplest local-server option.
Who it’s for Anyone who’s completed Module 2. No engineering background required — but you should be comfortable opening a terminal when your AI assistant asks you to.

After this module, you’ll be able to

  • 1 Build and serve a real, interactive local webpage from raw data — with AI doing most of the technical work, not just describing what a report should look like.
  • 2 Notice when a “successful” rebuild quietly didn’t work — a rebuild that doesn’t crash isn’t the same as one that worked.
  • 3 Fix the real cause, not the symptom — so the fix survives the next rebuild instead of breaking again the moment new data shows up.

Preparation

  • 1 Read the facilitator manual in full, especially “The Beat Two answer key” — the fastest way to recognize a correct diagnosis when you see one.
  • 2 Run the manual’s Quick Start yourself, end to end — build, drop in the new file, rebuild, fix — before teaching it live. Watching your own terminal do it is not optional prep here.
  • 3 Skim the deck’s speaker notes for timing and beat-by-beat framing language.
  • 4 Confirm your room’s AI assistants can actually execute code / run local commands, and that Python 3 is available — Beat One depends on it. This is the one logistics dependency worth checking before the session, not during it.
  • 5 Keep your own working reference report (from the Quick Start) open in a separate tab — ready to share only if a group gets genuinely stuck, not up front.
